# Gin 学习扩展资源

> 本目录只保留 Gin 相关内容（Gin 基础 + go-gin-api 企业级实战），来源为 xinliangnote/Go 的 Gin 部分。

## 本目录内容

- `01-Gin框架/` —— Gin 基础 6 篇（安装、路由配置、日志记录、数据绑定和验证、自定义错误处理、统一 API 错误码），含可运行 codes
- `03-go-gin-api [文档]/` —— go-gin-api 企业级实战 7 篇（go modules 初始化、目录规划与参数验证、中间件：日志/异常捕获/Jaeger 链路追踪/签名验证）

> 原 `00-基础语法/`（Go 语法）已移至 `golang/xinliangnote-Go基础语法/`；
