# evo1ve

> A collection of course notes assembled like puzzle pieces to construct my knowledge architecture. Always evolving.

**无限进步** — learning doesn't stop after graduation or once work begins. This repository is where the learning continues: one course, one book, one experiment at a time.

Every course is a puzzle piece. The notes are the edges that connect them, and over time the pieces snap together into a coherent knowledge architecture — one that is never finished, always evolving. Hence the name: **evo1ve**.

## How Notes Are Organized

- **One folder per course** — course materials (slides, PDFs, mind maps, code) sit together with handwritten markdown notes.
- **Piece by piece** — each note captures a single idea; related pieces connect into a bigger picture.
- **Always a work in progress** — notes are revised and reshaped as understanding deepens.
